Child health tracker

A clearer picture of growing up. A full-stack application for tracking children’s health and visualising their progress.

  • Django
  • JavaScript
  • SQLite
Explore project

A piece of software that can be used to keep track of children’s health. You can create an account which has all the personal information stored inside an SQLite database with the password encrypted. The user can create child profiles and input/modify child’s health data which can generate graphs to show how the child is getting on health wise for each health category. The user can switch to a specific child to be represented on the website. I was responsible for 70%+ of the project which included the graph generation, all the backend, and the home page.

Created
Oct 2024-April 2025, University team project
Skills & technologies
HTML, CSS, Django, JavaScript, Charts.js, SQLite, Git, Jira, encryption, exception handling

02
Game development2022

Tank Attack

Nine maps. Five tanks. One mission. A strategy-driven game with enemy AI and A* pathfinding.

  • JavaScript
  • p5.js
  • A* pathfinding
Explore project

A single player tank game which involves traversing a series of maps while destroying tanks and picking up coins. The player gets the option of 5 tanks on the opening screen UI which all have advantages and disadvantages. Each tank has a main attack which charges, a mini attack which can be used consistently, and a super ability which can be used after attacking enemy tanks enough. The game ends after losing or defeating all 9 maps, the points you earn from collecting coins and defeating enemies is taken off of your time in a ratio of 1 second : 5 points to give a final time.

Created
Throughout 2022, A level CS project
Skills & technologies
HTML, CSS, JavaScript, p5JS library, OOP, collision detection, A* pathfinding algorithm, random item generation, tank selection UI, game over screen
Development tools
Replit
