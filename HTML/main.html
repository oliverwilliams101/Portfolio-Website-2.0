Visualising search algorithms web application

An interactive graph editor for building, saving, and stepping through search algorithm visualisations.

  • React
  • D3.js
  • FastAPI
Explore project

This final year university capstone is a web application where users can create graphs and save them to their personal accounts, then run search algorithms on them. It includes DFS, Dijkstra’s, and A*, as well as less common algorithms such as Fringe search. Users can let the visualisation advance automatically or step through it manually, including returning to a previous step. The console updates to show the state of the data structures used by each algorithm.

Created
Oct 2025 – May 2026, University capstone project

Tank Attack

A strategy game with nine maps, five selectable tanks, enemy AI, and A* pathfinding.

  • JavaScript
  • p5.js
  • A* pathfinding
Explore project

A single player tank game which involves traversing a series of maps while destroying tanks and picking up coins. The player gets the option of 5 tanks on the opening screen UI which all have advantages and disadvantages. Each tank has a main attack which charges, a mini attack which can be used consistently, and a super ability which can be used after attacking enemy tanks enough. The game ends after losing or defeating all 9 maps, the points you earn from collecting coins and defeating enemies is taken off of your time in a ratio of 1 second : 5 points to give a final time.
