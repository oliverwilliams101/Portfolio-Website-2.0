Child health tracker

A full-stack application for recording children’s health data and viewing it in charts.

  • Django
  • JavaScript
  • SQLite
Explore project

A piece of software that can be used to keep track of children’s health. You can create an account which has all the personal information stored inside an SQLite database with the password encrypted. Tank Attack

A strategy game with nine maps, five selectable tanks, enemy AI, and A* pathfinding.

  • JavaScript
  • p5.js
  • A* pathfinding
Explore project

A single player tank game which involves traversing a series of maps while destroying tanks and picking up coins. The player gets the option of 5 tanks on the opening screen UI which all have advantages and disadvantages. Each tank has a main attack which charges, a mini attack which can be used consistently, and a super ability which can be used after attacking enemy tanks enough. The game ends after losing or defeating all 9 maps, the points you earn from collecting coins and defeating enemies is taken off of your time in a ratio of 1 second : 5 points to give a final time.

Created
Throughout 2022, A level CS project
Skills & technologies
HTML, CSS, JavaScript, p5JS library, OOP, collision detection, A* pathfinding algorithm, random item generation, tank selection UI, game over screen
