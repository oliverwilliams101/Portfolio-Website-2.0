# Oliver Williams — Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript. No packages or build step are required.

## Preview

Open `index.html` in a browser, or run this command from the project folder:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit <http://127.0.0.1:8000/>. The root page opens `HTML/main.html`.

## Editing

- `HTML/main.html`: introduction, projects, about section, and contact links.
- `CSS/main.css`: responsive layout and both colour themes.
- `JS/main.js`: project filters, detail dialogs, mobile navigation, and saved theme preference.
- `images/`: original project screenshots.

Project descriptions remain available through native expandable details when JavaScript is disabled. Theme storage is optional, and reduced motion preferences are respected.
